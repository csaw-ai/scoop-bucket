# NicholasCullenCooper Scoop Bucket

Scoop bucket for installable releases from Nicholas Cooper projects.

## csaw

Add the bucket and install `csaw`:

```powershell
scoop bucket add nicholascullencooper https://github.com/NicholasCullenCooper/scoop-bucket
scoop install csaw
```

`csaw.json` is generated by GoReleaser from
[NicholasCullenCooper/csaw](https://github.com/NicholasCullenCooper/csaw)
releases.
